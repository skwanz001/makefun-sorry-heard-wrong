One-line apology a smart speaker gives its owner after mishearing them — a plausible mishearing ("goodnight" heard as "goodbye forever") the speaker has already acted on, landing on a warm, concrete image no other entry will have. Written for make.fun's "Sorry, I Heard That Wrong" bounty: a single line of at most 140 characters, judged on humour first, freshness second, then how much it sounds like the device itself.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (Python 3.13 standard library only, no third-party imports).
